## 三套材料的边界

- [Markdown原件](01_全套重构文档_MD版/) 与 [TXT原件](02_全套重构文档_TXT纯文本版/) 是用户提供的来源副本，完整保留供查阅；历史快照路线和数字不可直接当作当前状态。
- [可覆盖快照](03_可直接覆盖到仓库根目录/) 已同步当前入口、相关模块与着色器。`.gdignore` 防止模板脚本参与Godot导入；整体覆盖前先看执行对照，避免倒退已验证实现。
- 本目录其他施工文档按当前工程校准；若与源码冲突，以源码和根 `PROJECT.md` 实测状态为准，并更新执行对照。
