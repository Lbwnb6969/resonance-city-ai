# 纸本界面与游戏文案

本次试装来自用户提供的本地 `UI/resonance-city-ai-main`。参考副本完整保留在原位，Godot通过 `.gdignore` 跳过扫描，GitHub不重复上传整套项目。实际适配代码位于 `scripts/ui/`，沿用当前游戏状态、编辑、收藏、居民与音乐系统。

## 视觉与布局

暖棉纸、植物墨绿、鼠尾草灰绿与铜金细边框；圆角卡片和柔和阴影。主题代码为 [valley_ui_theme.gd](../scripts/ui/valley_ui_theme.gd)，统一按钮、选项、输入框、下拉菜单、进度条、滚动条、页签及提示框。

| 区域 | 实际行为 |
|---|---|
| 左上纸卡 | 标题、随晴昼/夕照/星夜变化的副标题、房间概况；双列作品/试听/手记/地标/账本/手札入口 |
| 营造小目标 | 默认折叠，点击展开建设目标和生活概况；再次点击收起 |
| 右上动作 | 保存、音乐、光线、全景、漫步与明信片 |
| 右侧抽屉 | 只显示当前工具相关道路、用途、植被、水岸、街坊或地形设置；建筑面板可滚动 |
| 底部工具坞 | 1～9切换九种工具，撤销/重做；左下显示当前手势说明 |
| F1手札 | 四页签：营造手势、烟火与进化、声学与时代、快捷键速查；J/L面板也能跳转 |

紧凑布局见 [city_creation_paper_hud.gd](../scripts/ui/city_creation_paper_hud.gd)。手札见 [city_creation_guide_panel.gd](../scripts/ui/city_creation_guide_panel.gd)：打开时取消未落定笔画，阻止世界建造输入，暂停漫步镜头移动，城市生活和音乐继续；Esc或F1关闭。

## 文案来源

[city_creation_copy.gd](../scripts/ui/city_creation_copy.gd) 管理标题、三时段副标题、九工具名称/提示、八用途说明、样式名称、五种器乐主题、时代介绍、品质提示、地标副标题和四页手札正文。数值进度与解锁状态继续直接读取State/Life，避免静态手册与玩家实际进度分离。

| 时段 | 副标题 |
|---|---|
| 晴昼 | 河湾晨曲 · 留下你的街坊 |
| 夕照 | 暖金夕照 · 街灯与晚风渐起 |
| 星夜 | 星夜灯火 · 万家暖窗共鸣 |

工具依次为房屋、露台、道路、移除、用途、植被、水岸、街坊、地形。用途依次为居所、面包坊、演奏庭、制琴坊、花圃茶座、人文书院、钟表工坊、交响音乐厅。人文书院的画师送装挂毯和彩窗，钟表工坊送装八音盒与风向标；用途抽屉显示各自的实际工艺履历，账本展示库存、工人、配送和暂停原因。

参考手册中部分名称、时代条件与代码不一致，试装按当前实现校正：

| 时代 | 开启条件 |
|---|---|
| 田园木石 | 开局可用 |
| 文艺复兴 | 14屋、真实茶聚、完成跨街坊器乐问答 |
| 蒸汽钟表 | 28屋、两种时代的实际街坊 |
| 现代生态 | 50屋、完成贯通三个时代的共鸣 |

五级品质名称直接读取 `State.Quality.NAMES`。Lv.2住户步速+8%；Lv.4的连廊与花架体现生活履历，店家与工坊制作速度+25%，与演出余韵的+25%相乘。六地标的实际条件、是否落成与可用按钮直接读取 `State.Signatures`；植物宫无需先开启第三时代，水上剧场需要第四时代与三章手记。

## 操作与验证

按P切到用途/试听工具，点房或按住左键划过屋顶演奏；道路R切曲线/直拉，直拉时空格/右键锁段；Ctrl+O打开收藏与18座示范，首张是127屋四时代旗舰城。其余手势见游戏内F1或 [快速开始](Demo快速开始.md)。

`tools/check_creation_paper_ui_live.gd`：Compatibility实窗49项通过，实际鼠标操作九工具、道路样式、四页签、J/L跳转及模态输入阻断；1440×900与1024×768布局通过，原城市/撤销历史/个人继续档不变。`tools/check_creation_guidance_live.gd`验证原成长引导、选工具、手记收录与星夜漫步继续有效。截图和结果在本地 `验证记录/纸本UI试装_2026-10-18/`，不打包试玩ZIP。
