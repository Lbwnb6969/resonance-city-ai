## 先玩五分钟

1. 按1点房屋侧墙扩房、点顶面加层；空地点击建新屋，按住拖出一排。按2在屋顶留露台，有净空时自然出现花架与布篷。
2. 按3沿门前画小路，跨河会补桥，连通两岸居民生活。R切自由曲线/直拉，直拉时空格或右键锁段，Esc取消整笔。
3. 按5选房，改名字、配色/样式，或设面包坊、制琴坊、花圃茶座、演奏庭。先保留居所并接上道路，观察人真实到岗、采购和回家。
4. 按7画池塘，岸边会留下湿砂和扁石，池中出现有限浮叶/花。按9刷草丘、露岩或平顶台地，默认自然轮廓收放坡肩，关闭勾选可画规整圆丘，Shift临时压低；再按1在高处起屋、按3接路，陡坡自动铺石阶。新屋记住起笔海拔，水平扩房保持同一层地板。
5. 按8刷街坊、选音乐主题；选演奏庭邀请演出，街坊沿路到齐后演奏。J看成长手记，点「下一件事」或各目标按钮，镜头会带到对应位置，并选好工具、显示具体做法；L看生活账本里的库存、工人和停产原因，Ctrl+O收藏完整作品。

红色预影表示本笔与结构、水域或支撑规则冲突；调整位置再落定。建设立即提交，不等待音乐资格。

## 九大工具

| 键/工具 | 操作 |
|---|---|
| 1 房屋 | 点墙扩展、点顶加层；拖动同一宿主/楼层建整笔，空地起笔建新屋；邻屋自动贴齐，Alt自由放置 |
| 2 露台 | 点墙伸出、点顶留花园；可连拖同层，系统补栏杆与支撑。工具4点布篷也能移除原露台 |
| 3 道路 | R/UI切自由曲线/直拉，Alt起笔临时直拉；按住左键画，直拉时空格/右键锁段，松开提交；Shift点击擦除整条路 |
| 4 移除 | 点单元，附属失去支撑层一起移除；面板选整栋或Shift点击；撤销恢复 |
| 5 用途/样式 | 点房选中，改名后Enter；选五用途、灰泥/木构/石砌、配色，面包坊/工坊可开停生产，演奏庭可邀请/结束演出 |
| 6 植被 | 选橄榄/柏/灌木与笔刷大小，拖左键画；Shift擦除；自动避开房、路、水，建设冲突时保记录并隐藏 |
| 7 水岸 | 选池塘/引水渠与宽度；池塘空地起笔，引水从已有水边起笔；Shift点击填回自建水，主河保留 |
| 8 街坊 | 拖动划区、点击选区；起名、选五主题，面板可开用途配器/邻里对答；Shift移除整区，后画区域覆盖成员归属 |
| 9 地形 | 抬高/压低/还原/露岩草丘/平顶台地/柔化缓坡，2/3.5/5m笔刷；自然轮廓开关、Shift起笔临时压低，一笔一次撤销 |

Esc取消未落定笔画；切工具也会取消。鼠标在UI上松开不把草稿误建到世界中。

## 镜头与保存

| 快捷键 | 行为 |
|---|---|
| 滚轮 / 右键 / 中键 | 缩放 / 转动 / 平移镜头 |
| H / F | 恢复全景 / 隐藏界面拍照 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+S | 保存当前继续作品 |
| Ctrl+O | 打开作品收藏，保存完整可编辑版本；“示范河湾”页签可切换17座内置样例 |
| J / L | 河湾手记 / 生活账本；Esc返回 |
| P / ♫ 点房试听 | 进入用途与试听视图，逐栋点按弹奏；按住P移动光标或按住左键划过不同屋顶可连续刮奏，不改作品或撤销历史 |
| V / 漫步按钮 | 进入街头透视视角；WASD/方向键行走、右键转头，再按V恢复原镜头 |
| F12 | 拍下带纸框和日期的明信片，保存在 `user://postcards/`；创作或漫步视角均可使用 |
| 音乐 / 光线按钮 | 静音或开启音乐 / 晴昼→夕照→星夜循环 |

继续档位于Godot `user://city_creation_v1.json`；作品收藏在 `user://city_creation_works/`。收藏可同名留新版本，打开另一作品前先保留当前作品，恢复房路、居民行程、库存、演出进度及镜头光线。关闭窗口保存已有编辑，未落定草稿不写入。从隔离样例启动不自动写个人继续档。游戏内切换示范会先把当前河湾留在“我的作品”，可随时回开；正常继续模式下，选中的示范及后续编辑作为当前继续作品。

## 建筑与生活反馈

- **长屋/钟楼/庭院**：连排形成连续屋脊与山墙圆窗；独立顶层连续叠至三层、有净空时形成尖顶钟亭；底层闭合房环包住至少4格合法干地，会派生石铺与可容纳的喷泉。开墙/撤销后自然重算。
- **面包坊**：工人沿路到岗、有柜台容量才烤，居民真正到店完成驻留才购买。开炉时屋顶升烟；暂停、满柜或休息停烟，已有库存仍可出售。镜头在附近时，真实出炉与采购会在下一乐句轻响木音/拨弦，从面包坊方向传来；忙时留白，同刻发生优先采购，正式演出时静候。
- **制琴坊**：匠人真实制作并携货送到可达房屋，安装后逐级获得风铃、窗饰/花箱和木廊。断路保留在途货物，接通后继续；演奏庭还可发节庆布置委托。
- **花圃茶座**：有合法席位、至少两位有资格居民真实到齐才品茶结算，成功茶聚可支持自发巡演。
- **演出/接力**：演奏庭邀请街坊，沿路到齐后等乐句开始完整24秒演出；附近房屋亮窗摆旗应答，完成后获得余韵。接通至少两庭时，可从用途面板开始有限庆典接力；取消不算成功。
- **音乐街坊**：暖庭、深流、织机、市集、林间五主题；用途配器默认关闭，开启后下一乐句交接。邻里短句对答取实际短路关系；桥拱华彩要等居民真的经过。静音后生活照常。

四章手记依次记录：①现存跨水桥、烤出面包、成功演出；②九屋、真实茶聚/木饰交付、两种有住户主题；③二十六屋、独立钟楼、成功演出消费节庆布置；④高地居所、景观道路、圆塔/花房/柱廊及跨区音弧。原四配色随时可选，章节饰色永久保留，不锁自由建设。

第四章“星夜百鸟与立体交响”在第三章后开启：留下一座海拔≥0.8m的高地房屋、铺出灯街或汀步、派生圆塔/花房/柱廊之一，并连起跨区共鸣音弧，即可获得“星夜鎏金与月白”饰色。

选址会反哺经营：靠水/喷泉的面包坊提速35%、每炉多1份；8m内至少3棵可见橄榄或柏树的工坊提速35%；临灯街或池塘的茶座将余韵延长至45秒。L账本显示加持和逐户共鸣：本户真正买过面包、参加茶叙/获得余韵、收到匠作各贡献一阶；幸福居所添花盆和彩旗，街坊平均达到二阶后共享伴奏更丰满。

屋顶白鸽起落、建设或拨弦时惊飞，花木/池畔的彩蝶在星夜变成流萤。相对二层外墙满足跨度与净空时自动拉起彩旗暖灯；拆除或撤销后随建筑更新。星夜有人居所保留琥珀窗光，音乐窗光继续在其上呼吸。

高地样例有2米高庭与连接原街道的石阶；选择高庭改用途或邀请演出，可观察居民登高。保存为Schema 6，旧作品缺失海拔仍按0米读取；建好后再改地形不会搬动已保存的房屋地板。

工具3沿整条已有窄路再描一遍，会原位铺成1.75m石板宽街；也可勾选“石板宽街”直接修路。第三次描画不叠路，Ctrl+Z一次还原。门口/路口/桥面/陡阶留净空，街灯在夕光与真实开演时亮起。贴墙窄路拓宽侵入房屋会拒绝，可改走正对门口的宽街支路。

工具5选择房屋样式“圆塔 · 望楼”：独立房柱变成石塔与曲面尖顶，继续用工具1向上加层；水平扩房或穿拱时保留原结构，收回扩房后恢复圆塔。用途、路口和经营进度保持，封闭望楼没有额外塔铃。圆塔作品保存为Schema 8。

工具2在同一栋屋上连出至少两格同层上层露台，开阔处会自动生成玻璃花房；最多选连续四格长排。花架让位于花房，邻屋或上方遮挡时保留原露台，撤销加建后花房恢复。玻璃仍可点击选中原露台，切换夕光看暖绿透光。

底层房格上方有房间，外墙紧邻同高1.75m石板灯街或闭合石铺庭院时，内墙自动后退0.38m，原外沿生成石柱和拱券。门窗与亮窗跟随退墙，拱下留真实空隙；拆掉上层后恢复普通立面，撤销可恢复柱廊。街道仍须正面接门才能接通入口，样例保留短门径。

工具3用普通小径横跨宽度小于2.6m的低岸引水渠，会自动派生微露水面的青石汀步；主河、池塘、宽街、高岸和水上路口保留桥。居民真实踩过石块才发出随当前和弦的轻水滴木琴声与涟漪，静音统一控制。移除道路收回石块与声音来源，撤销恢复。

建屋、加层或留露台后，会立即弹出该房屋的音符；按P后点一排屋子或按住P划过不同屋顶，也能直接弹奏。低屋取根音/三音，二层取五音/六音，更高房屋取高八度；暖庭木吉他、深流竖琴、织机马林巴、市集手风琴、林间长笛随真实街坊主题变化。窗光随短音向上闪烁；静音统一关闭，正式演出期间让出演奏。

镜头靠近河流或池渠，溪流声会轻轻淡入；看向树林能听到林风和白昼鸟鸣，切夕光则渐变为虫鸣。演出与点房拨弦期间环境声自动压低，右上「音乐」按钮同时静音音乐与自然声，恢复后平滑淡入。

工具8勾选「♫ 连接共鸣街坊」，从一个街坊或区内房屋拖到另一片街坊，松开后保留音弧；Shift同样拖动可断开，Esc取消当前手势。隔河不造桥也能按乐句一问一答，正式演出时直连另一端的房屋隔岸亮窗，第八乐句加入对应主题合奏。音乐连线不接通居民通路；本地居民仍须沿真实道路到齐。连线随作品保存（Schema9），旧作品缺省无连线，删街坊会同步收回相关连线，撤销恢复。

当前实际进度与v3剩余工作看 [PROJECT](../PROJECT.md)，代码模块看 [3D架构](21_新城创作切片.md)。

可编辑河湾现为80×80米。滚轮可缩至100米，H或右上角“全景”查看整个画布，中键平移到新区域继续建屋、铺路、塑形与种植；旧作品保留原坐标和内容。

手记收录四章后仍可继续自由建设；手记里的「星夜漫步」可切入自己的街巷。普通木饰送往22米内邻屋；节庆委托沿相通路网送达，不受普通范围限制。茶座需要两位实际买过面包的住户；断路或只有一人入座时，面板和账本会说明当前等待的条件。

工具9「自然轮廓」只影响新画的草丘、洼地、露岩和平顶台地；旧作品原样保留。外圈表示最大作用范围，台地内圈表示保证平顶，沿不规则坡肩可继续柔化。自然轮廓作品保存为Schema11。

拖动地形笔刷时，可看到整条笔画的最大范围；平顶模式还有连续的保证平顶内界，末端圆圈标当前笔头。闭合笔画会保留中间未覆盖的内岛。范围线沿当前地貌显示，松手后才真正塑形；自然坡肩会在最大范围以内收放，Esc可取消整笔。

按5选中居所，右侧会显示「居所共鸣」及麦香、茶叙、匠心三项日常。圆点随这户真实采购、茶聚／演出余韵和木饰送装点亮；下一步会说明缺店、接路或22米内送装范围。无需重新选屋，进度每半秒更新；店家的详细库存和停产原因仍可在生活账本查看。
