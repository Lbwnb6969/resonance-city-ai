# GitHub 与本地的项目资料

主仓库 [resonance-city-ai/main](https://github.com/Lbwnb6969/resonance-city-ai/tree/main) 同步本地完整的Git项目文件树。文档、代码、运行资源、示范数据和已经纳入Git的参考资料保留相同路径与内容；不再限制为55MB精简快照。

四库阅读入口见 [参考索引](../文档/参考索引.md)。本地未纳管的原始恢复资产、分析数据库和工作缓存仍留在原目录，实际运行使用根项目 `资源/`、`资产/` 中已纳管的依赖。

`参考资料发布清单.json` 是此前选择研究资料时生成的历史清单，不代表当前仓库全部文件。当前版本范围以Git文件树为准；同步入口为 `tools/sync_github_main.py`，不重新生成逐文件哈希清单。

`.godot/`、机器连接配置、个人作品、`备份/`、`废弃/`、验证记录和交付包遵循根 `.gitignore`，完整保留在本地。
